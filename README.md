# 🌐 Meus Sites Favoritos

Este projeto consiste em uma página web desenvolvida com **HTML5**, cujo objetivo é apresentar uma seleção de cinco sites que considero interessantes e que fazem parte dos meus favoritos. A página apresenta imagens ilustrativas de cada plataforma, suas fontes e links que permitem acessá-las diretamente.

## 📌 Sites apresentados

O projeto reúne os seguintes sites:

| Site | Descrição |
|---|---|
| [Discord](https://discord.com/) | Plataforma de comunicação que permite conversar por texto, voz e vídeo. |
| [Steam](https://store.steampowered.com/) | Plataforma de distribuição digital de jogos para computador. |
| [Fandom](https://www.fandom.com/) | Comunidade de wikis e conteúdos sobre diferentes universos e franquias. |
| [Reddit](https://www.reddit.com/) | Rede social baseada em comunidades e discussões sobre diversos assuntos. |
| [MotionBGS](https://motionbgs.com/) | Site que disponibiliza vídeos e animações para utilizar como papéis de parede. |

## 🛠️ Tecnologias utilizadas

- **HTML5:** utilizado para estruturar e organizar os elementos da página.
- **Imagens:** utilizadas para ilustrar visualmente cada site.
- **Links externos:** permitem acessar as plataformas apresentadas.

## 📂 Estrutura do projeto

```text
Meus-Sites-Favoritos/
│
├── lista-favoritos.html
├── reddit-capa.webp
└── README.md
```

- `lista-favoritos.html`: arquivo principal que contém a estrutura da página.
- `reddit-capa.webp`: imagem utilizada para representar o Reddit.
- `README.md`: documentação e apresentação do projeto.

## ▶️ Como visualizar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `lista-favoritos.html`.
4. Abra o arquivo em qualquer navegador de internet.

## 🎯 Objetivo

Este projeto foi desenvolvido como atividade prática de aprendizagem, com o propósito de exercitar os conhecimentos iniciais em HTML5, especialmente a utilização de títulos, imagens, links, legendas e elementos de organização de conteúdo.
